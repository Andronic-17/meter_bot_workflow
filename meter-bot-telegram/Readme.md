# 🤖 Meter Bot — Telegram-бот для сбора показаний счётчиков

Автоматизированный Telegram-бот, который принимает фотографии счётчиков, распознает показания с помощью ИИ-зрения (OpenAI GPT-4o) и сохраняет их в базу данных PostgreSQL (Supabase).

## 🎯 Решаемая задача
Ручной сбор показаний счётчиков — рутинная задача. Этот бот автоматизирует процесс: пользователю достаточно отправить фото, а система сама распознает цифры, привяжет их к конкретному пользователю и сохранит в базу.

## 🛠 Стек технологий
- **n8n** — оркестрация workflow.
- **Telegram Bot API** — интерфейс взаимодействия с пользователем.
- **OpenAI (GPT-4o)** — распознавание показаний с изображений (Computer Vision).
- **PostgreSQL (Supabase)** — хранение данных пользователей и показаний.
- **Docker** — развертывание n8n.

## ⚙️ Как это работает
1. **Триггер:** Бот получает сообщение в Telegram.
2. **Маршрутизация (Switch):**
   - Команда `/start` → Регистрация пользователя в БД и приветствие.
   - Фото счётчика → Отправка в OpenAI для распознавания.
   - Другое → Подсказка пользователю.
3. **Распознавание:** OpenAI анализирует фото и возвращает только числовое значение показаний.
4. **Сохранение:** Данные записываются в таблицу `meter_readings` с привязкой к `user_id`.
5. **Обратная связь:** Бот подтверждает сохранение и отправляет распознанное значение.

## 🗄 Структура базы данных
Workflow автоматически создает необходимые таблицы при первом запуске:
- `meter_users` — хранит `telegram_id`, имя и username пользователя.
- `meter_readings` — хранит показания, метку счётчика (из подписи к фото) и привязку к пользователю.

## 🚀 Как запустить
1. Импортируйте файл `meter_bot_workflow.json` в свой инстанс n8n.
2. Настройте credentials (учетные данные) для:
   - Telegram API (токен бота).
   - OpenAI API (ключ).
   - PostgreSQL (данные подключения к Supabase).
3. Активируйте workflow.
